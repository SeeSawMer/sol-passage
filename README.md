# Sol Passage
共通テスト『情報Ⅰ』の学習を、診断・演習・知識管理・成長記録まで一貫して支援する学習プラットフォーム。

## プロジェクト概要

Sol Passage は、大学入学共通テスト「情報Ⅰ」の学習支援を目的としたWebアプリケーションです。

診断して終わりではなく、学習者の知識習熟度を把握し、不足している分野を可視化するとともに、問題演習や解説を通して知識を補い、共通テストで必要となる基礎力・応用力の定着を支援します。

---

## 開発目的

主な対象は、大学入学共通テスト「情報Ⅰ」を受験する高校2年生・高校3年生・既卒生です。

現在の勤務校の生徒を中心に利用することを想定し、教科書で学ぶ内容に加え、情報分野で必要となる技術用語や基礎知識を確認・定着できる教材を提供することを目指しています。

将来的には、学校や教科書の違いに左右されず、多くの学習者が利用できる学習支援システムへ発展させることを目標としています。

---

## 特徴

- 知識習熟度の診断
- 分野別の弱点分析
- 不足している知識を補う問題演習と解説
- JSONによる問題データ管理
- GitHub Pagesで動作する軽量なWebアプリケーション
- 外部ライブラリを使用しないシンプルな構成
- 共通テストを意識した段階的な問題演習
- 学習履歴・成長記録の可視化
- 個人名を表示しない匿名ランキング機能（本人のみ順位を確認可能）
